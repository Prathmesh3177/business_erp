## 2. Core V1.5 Workflows & Architectural Invariants

### 2.1 Isolated Mobile Data Mode & Single-Authority Architecture
- **Authority Constraint**: Per ADR-013 and architecture design (`docs/05-sync-and-cloud.md`), mobile devices operate in an isolated local draft mode. The main desktop installation retains sole posting authority for stock, financial journal entries, and document sequence generation.
- **UI Policy**: Mobile navigation shell displays a persistent warning banner: **"Isolated Mobile Data Mode — Local Offline Drafts"**.

### 2.2 Mobile Camera & Attachment Compression (`MobileCameraAdapter`)
- **Image Compression**: `MobileCameraAdapter` in `packages/erp_platform` compresses and resizes raw camera/gallery captures to 1920x1080 JPEG payloads with 85% quality preservation.
- **Integrity**: Generates SHA-256 hash checksums and thumbnail preview bytes for equipment nameplate photos and documents.

### 2.3 App Lifecycle & Draft Recovery (`AppLifecycleDraftHandler`)
- **Auto-Save**: Active POS sales carts and inventory adjustment drafts automatically persist to local storage when app enters `paused` or `detached` states.
- **Crash Recovery**: Relaunching the app detects uncommitted drafts and prompts the user to restore or discard them without data loss.

### 2.4 Warranty Entitlements & Local Reminder Queue
- **Categorization**: Warranty entitlements categorized by status:
  - **Active**: $> 30\text{ days}$ remaining.
  - **Expiring Soon**: $\le 30\text{ days}$ remaining.
  - **Expired**: $< 0\text{ days}$ remaining.
- **Deduplication**: `GenerateWarrantyRemindersUseCase` deduplicates reminders using primary key `partyId_serialId` to suppress duplicate notifications.
- **Formula Injection Protection**: `ExportWarrantyRemindersUseCase` sanitizes CSV exports (prefixing `=`, `+`, `-`, `@`, `\t`, `\r` with `'`).

### 2.5 Hardware Transport Capability Detection (`MobilePrintTransportManager`)
- **Transport Types**:
  - `osSpooler`: Standard OS print spooler / PDF exporter (Available on all platforms).
  - `bluetooth`: Bluetooth SPP / LE thermal printing (Supported on Android host).
  - `network`: Wi-Fi direct TCP RAW socket port 9100.
  - `usbOtg`: USB OTG POS printer connection (Supported on Android host).
