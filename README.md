# Solar Shop ERP

Architecture and implementation plan for a local-first solar retail and installation business. The workspace contains the documentation baseline, a minimal generated Flutter shell under `business_erp`, and isolated P00 feasibility spikes; no ERP feature or production schema is implemented yet.

Start with [the documentation index](docs/README.md), then follow [the phase roadmap](docs/09-roadmap.md) and [the implementation prompts](docs/prompts/README.md).

Scope: Windows, macOS and Android; POS, GST billing, inventory, purchases, accounts, printing, English/Marathi, backup, cloud synchronization, branches, quotations, installations, warranty, service and AMC.

**No product AI features are included in any release.** The prompts are instructions for an AI coding assistant to implement conventional software.
